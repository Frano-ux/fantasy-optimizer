# Fantasy Optimizer

A personal, non-commercial fantasy football tool for my own team in one private Yahoo Fantasy Football league.

## What it does
- Projects player scores in my league's exact scoring rules, using public historical NFL statistics (nflverse)
- Suggests my weekly starting lineup
- Estimates my odds in each weekly matchup
- Reviews my league's past seasons to check how accurate its projections are

## Scope
- Single user (me), single league, read-only
- Runs only on my own computer; not hosted, sold, or distributed
- No data from Yahoo is published or shared
